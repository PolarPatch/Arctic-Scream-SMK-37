ARCTIC SCREAMSMK-37

Arctic Scream on the M-VAVE SMK-37: the drones, the howls and the singing ice of the FM-1 firmware, on 37 keys, 16 pads, four faders and two wheels. This page runs the same code the keyboard will run. It is being built before the keyboard is here: nothing on this page has run on an SMK-37 yet.
